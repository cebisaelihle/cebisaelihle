## Featured Projects

### Remote Sensing Land-Cover Classification

Geoinformatics practical project involving the classification and interpretation of remotely sensed imagery using different supervised and unsupervised classification techniques. Methods explored include Random Forest, Support Vector Machine (SVM), Maximum Likelihood, Neural Networks/Deep Learning and ISO Cluster classification.

**Tools:** ArcGIS Pro, Remote Sensing, Random Forest, SVM, Maximum Likelihood, Neural Networks/Deep Learning, ISO Cluster

### Surface Water Change Analysis – uMgungundlovu District
Analysis of changes in surface-water extent within uMgungundlovu District using satellite imagery and geospatial techniques. The project involved extracting and analysing water-body areas over time using Random Forest classification. The study also used linear regression and Random Forest to examine relationships between surface-water changes, land-cover characteristics and climate variables.

Tools: ArcGIS Pro, Google Earth Engine, Landsat, R, Random Forest, Linear Regression, Spatial AnalysiS

### Gully Erosion Modelling – Central KwaZulu-Natal

GIS and remote sensing project investigating factors associated with gully erosion using terrain, rainfall and environmental datasets. The project involved spatial data preparation, environmental modelling and GIS-based analysis.

**Tools:** ArcGIS Pro, Remote Sensing, Spatial Analysis, RUSLE

### Flood Risk Assessment – eThekwini

GIS-based flood risk assessment using a multi-criteria approach. The analysis incorporated factors including elevation, slope, rainfall, land cover and distance from rivers to identify areas with different levels of flood risk.

**Tools:** ArcGIS Pro, AHP, MCDA, Spatial Analysis
